## Visual V2
Os antigos boards largos foram removidos do layout. A V2 usa:
- hero em proporção nativa (`hero-product-v2.webp`)
- cards das categorias feitos em HTML/CSS
- prévias individuais em WebP
- seção de planos em HTML/CSS
- imagem de apoio separada para a seção de público

Todas as imagens usam proporção preservada (`height:auto`, `object-fit`) para evitar distorção em celulares.
